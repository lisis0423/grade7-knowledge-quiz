# 知识闯关 · 七年级复习小游戏

在线版（GitHub Pages）：<https://lisis0423.github.io/grade7-knowledge-quiz/>

> 首次部署后需要 1–3 分钟生效；打不开时先确认仓库的 Pages 已经开启。

一个**不用联网、双击就能玩**的七年级知识点闯关游戏。孩子扮演外星侦查员 K-7，靠答对地理题完成地球测绘任务，应付督察突击检查，赚奖金、换装备、开宝箱。目前上线「地理」，其余科目已经留好接入接口。

- 按课本章节闯关，答对连击加分
- 答错的题自动进入错题本，重练答对后自动移出
- 进度、星星、错题都存在本机浏览器里
- 手机 / 平板 / 电脑自适应，支持鼠标和触屏

## 一、怎么打开

双击 `index.html` 即可（推荐 Edge 或 Chrome）。

第一次打开会先播放 6 格开场漫画，交代 K-7 的来历和任务；可以点“跳过”，之后在“设置 → 开场漫画 → 重看”随时回看。

不需要安装、不需要启动服务器、不需要联网。可以整个文件夹拷到 U 盘或另一台电脑继续用。

### 在手机上玩

手机浏览器不能直接双击本地文件，用下面任一方式：

**方式 A：电脑当小服务器，手机连同一个 Wi-Fi（最快，不用注册）**

1. 双击根目录的 `启动手机版.bat`；
2. 窗口里会打印一个类似 `http://192.168.1.5:8000` 的地址；
3. 手机连**同一个 Wi-Fi**，用浏览器输入这个地址即可；
4. 第一次运行时 Windows 可能弹出防火墙提示，请勾选“专用网络”并点“允许访问”。

电脑需要开着，那个黑色窗口不要关。关掉窗口服务就停了。适合在家里用手机或平板复习。

小技巧：打开后可以用浏览器的“添加到主屏幕”，下次点图标直接进，像一个小 App。

**方式 B：传到免费静态网站，随时随地打开（需要免费账号）**

把整个文件夹拖到 Netlify Drop（`app.netlify.com/drop`）、Vercel 或 GitHub Pages，会得到一个 `https` 链接。手机收藏这个链接即可，不再依赖家里的电脑。

**方式 C：直接把文件夹传到手机（仅 Android 较方便）**

用微信、QQ 或数据线把文件夹传过去，用支持本地网页的文件管理器打开 `index.html`。iOS 的 Safari 不能直接打开本地文件，不建议用这种方式。

## 三、玩法与反馈

### 1. 角色与任务

- 孩子是织女座观测站的侦查员 **K-7**，伪装成初一学生潜入地球，任务是补全星图。
- 每个章节是一个“任务”，进任务前会看到**任务简报**和督察台词；通关后是**任务报告**。
- 完成任务得 **金币 + 经验 + 评级**；经验升级后称号从“实习侦查员”一路升到“星图大师”。
- 每个任务独立记录三档难度的最佳成绩和星星。

### 2. 三档难度

| 难度 | 题目 | 规则 | 回报 |
| --- | --- | --- | --- |
| 🌱 基础 | 6 道选择/判断题 | 不限时，答错可再答一次，不扣分 | 奖金 ×1.0，经验 ×1.0 |
| 🛰️ 中级 | 本任务全部题目 | 不限时，答错扣 20 分 | 奖金 ×1.3，经验 ×1.2 |
| 🔥 高级 | 全部题目 + 已学章节的跨区题 | 每题 20 秒，答错扣 50 分，超时算错 | 奖金 ×1.8，经验 ×1.6，装备掉落率最高 |

高级档的跨区题只从“已经挑战过的任务”或“当前任务之前的任务”里抽，**不会考到还没学的章节**。

星级门槛也随难度提高：基础 50/70/90%，中级 60/80/95%，高级 80/90/100%。所以同一份 90% 的答卷，基础和中级拿的星不一样，想冲三星就得选高难度。

### 3. 常态反馈：奖金与装备

- 每答对一题 **+100 分**，连击每次额外 +20 分（最多 +100）。
- 任务结束按星级发金币和经验，评级从 **S / A / B / C / D**。
- 有概率掉落装备，品质分普通、精良、稀有、传说；高级任务更容易出好装备。
- 装备穿在 **工具 / 武器 / 防具 / 装扮** 四个槽位，效果真实作用于答题：
  - 🛹 飞行滑板：每关跳过 1 题
  - 📡 测绘扫描仪：排除一个干扰选项
  - 🛸 微型无人机：多一次重答机会
  - 🖊️ 等离子笔：答错时护住连击
  - 🔫 脉冲手炮 / 🛡️ 能量护盾：抵挡一次扣分
  - 🦺 侦查护甲：扣分减半
  - 🧥 隐身斗篷：每题多 10 秒
  - 🪽 星空翅膀、🪖 霓虹头盔等：装扮 + 得分/金币加成
- 补给（能量棒、星际糖果等）在装备舱里使用，直接换经验或金币。

### 4. 偶发奖励：连击宝箱

- 连续答对 **3 题** 会截获一个补给箱，连续答对 **6 题** 会截获大宝箱。
- 箱子是锁着的，**必须答对一道来自其他章节的题**才能打开。
- 答对拿金币，有机会开出稀有装备甚至翅膀；答错箱子溜走，只留 10 金币安慰奖。
- 宝箱题不算进本关成绩，也不会进错题本，纯粹是“顺手复习 + 抽奖”。

### 5. 督察追问

- 每关有一道题答错后，赫兹督察会追问一句，给出三个解释选项。
- 解释对了：**督察信任 +1，奖金 +20**；解释错了会被记一笔。
- 追问答对会写进任务报告，是“态度分”。

### 6. 错题与复习

- 答错的题立即进入错题本，任务报告里也会列出本次漏洞。
- 在“错题重练”里答对，才会从错题本移出。
- 选择题每局随机打乱选项，避免靠“选 A”蒙对。
- 学习报告汇总累计答题、正确率、星星、错题，以及角色等级、金币、信任度和收藏数量。

## 五、接入其他科目（3 步）

**第 1 步**：新建 `data/math.js`，照下面的结构写题库。

**第 2 步**：在 `index.html` 的题库区域加一行：

```html
<script src="data/math.js"></script>
```

**第 3 步**：打开 `data/placeholders.js`，把对应科目的 `available: false` 删掉（或改成 `true`）。如果 new 文件里已经注册了同名科目，也可以直接从占位列表里删掉那一条。

最小示例（数学）：

```js
(function () {
  'use strict';

  GameSubjects.register({
    id: 'math',
    name: '数学',
    icon: '📐',
    desc: '有理数、整式、一元一次方程',
    order: 2,
    levels: [
      {
        id: 'math-7a-1',
        title: '第一章 有理数',
        subtitle: '正负数、数轴、绝对值',
        questions: [
          {
            id: 'math-7a-1-q1',
            type: 'choice',
            stem: '−3 的绝对值是（　）',
            options: ['−3', '3', '0', '三分之一'],
            answer: 1,
            explain: '绝对值表示一个数到原点的距离，−3 到原点的距离是 3。'
          },
          {
            id: 'math-7a-1-q2',
            type: 'fill',
            stem: '5 的相反数是 ____。',
            accept: ['-5', '−5'],
            explain: '只有符号不同的两个数互为相反数，5 的相反数是 −5。'
          }
        ]
      }
    ]
  });
})();
```

### 题目字段说明

| 题型 | 写法 | 说明 |
| --- | --- | --- |
| `choice` 单选 | `options: [...]`, `answer: 1` | `answer` 是正确项下标（从 0 开始）；选项每局自动打乱 |
| `judge` 判断 | `answer: true / false` | 显示“正确 / 错误”两个按钮 |
| `fill` 填空 | `accept: ['答案', '同义写法']` | 题干用 `____` 表示空位；比较时忽略空格、全角半角和标点 |
| `match` 连线 | `left: [...]`, `right: [...]`, `answer: [2, 0, 1]` | `answer[i]` 表示左栏第 i 项连到右栏的哪一项 |

通用字段：

- `id` 题库内唯一，建议“科目-册-章-序号”
- `stem` 题干（必填）
- `explain` 解析（必填，答完会展示）
- `svg` 可选，内联的 `<svg>` 字符串，用于示意图
- `caption` 图的说明
- `hint` 填空提示

填空答案提示：把常见写法都列进 `accept`，例如 `['6371千米', '6371', '约6371千米']`。

### 关卡元信息

`levels` 里每一关支持 `id`、`title`、`subtitle`、`questions`。同一个科目可以拆到多个文件注册，关卡会按注册顺序追加。

## 六、自检

题库结构检查（不需要额外依赖）：

```bash
node tools/validate.js
```

它会把每关题数、题型分布、重复 id、答案下标越界、连线答案长度不一致等问题列出来。

端到端交互测试（需要 jsdom）：

```bash
npm install jsdom --prefix tools
node tools/e2e.js
```

覆盖首页渲染、任务简报、三档难度组题、完整答对一关、评级与奖金、连击宝箱、答错扣分、督察追问、限时超时、重答机会、装备跳过、装备舱穿戴、错题重练移除、学习报告等 **127 项断言**。

线上页面冒烟测试（需要 jsdom）：

```bash
node tools/online-smoke.js
```

它会直接加载 GitHub Pages 上的线上地址，检查资源加载、开场漫画、任务列表、难度选择和答题流程，共 25 项。

## 七、说明与限制

- **开场漫画**：6 格漫画交代了 K-7 的星系（银河系猎户臂）、母恒星（天琴座方向织女一）、第 3 颗行星（织女三号）、Ⅱ 型文明、所属部门（测绘总局第七观测站外勤侦查处）、上级（赫兹督察）、任务（11 个测绘任务 + 突击检查）和降落伪装。天琴座方向的行星系统属于**虚构设定**，用于故事，不是真实天文事实。
- **存档**：使用浏览器 `localStorage`，只存在当前设备、当前浏览器。清理浏览器数据会丢失进度、金币和装备；隐私模式下可能只能临时保存（脚本已做降级处理，不会报错）。
- **奖励定位**：金币、经验、装备、宝箱是游戏化反馈，用来维持兴趣，不代表学习评价。真正反映掌握程度的是**正确率、星星和错题本**。
- **难度选择**：建议先用基础档预习、中级档巩固，学过之后再挑战高级档。高级档的跨区题只从已学或更早的任务里抽，不会超纲。
- **示意图**：SVG 图是为了说明知识点而绘制的简化示意图，不按严格比例尺，不能当作真实地图使用。
- **教材版本**：章节顺序按人教版 2024 年版七年级教材编排。如果学校使用其他版本，可以只改 `data/*.js` 里的 `title`、`subtitle` 和题目，界面代码不用动。
- **题目范围**：以课本核心知识点为主，用于预习和复习自测，不替代课本和老师的讲解。
- **音频**：音效由浏览器实时合成，没有外部音频文件；可在设置或顶栏关闭。
